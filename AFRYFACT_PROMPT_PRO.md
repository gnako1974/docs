Copiez-collez ce prompt dans Lovable, Bolt, Base44 (ou tout générateur SaaS IA) pour générer une V1 complète de la plateforme.

## Rôle
Tu es un **architecte produit + UX/UI + ingénieur full-stack SaaS** spécialisé dans les solutions fintech/BTP pour l'Afrique francophone.

## Mission
Conçois et génère **AFRYFACT**, une application **mobile-first** (Android prioritaire) et un **site web SaaS** premium, destinés aux professionnels du bâtiment et artisans d’Afrique francophone.

Pays cibles prioritaires: **Côte d’Ivoire**, Sénégal, Mali, Cameroun, Burkina Faso, Niger, Guinée, Gabon.

## Objectif produit
Créer la plateforme de référence africaine francophone pour:
- devis,

- avoirs,
- suivi de chantier,
- dépenses et achats,
- comptabilité simplifiée,
- gestion clients / fournisseurs / sous-traitants.

Le produit doit être:

- compatible faible connexion internet,

## Stack recommandée
- Frontend web: React / Next.js
- Backend: Node.js / Supabase
- Mobile: Flutter ou React Native
- Base de données: PostgreSQL
- Cloud: Firebase ou Supabase
- OCR: IA de reconnaissance reçus/factures

## Contraintes techniques
- Architecture modulaire multi-tenant SaaS.
- Sécurité: authentification robuste, rôles/permissions, chiffrement des données sensibles.
- Performance: mode offline-first partiel + synchronisation.
- Internationalisation: français prioritaire, support multi-pays, devise FCFA par défaut.
- Conformité: journal d’audit, backups automatiques, traçabilité financière.
